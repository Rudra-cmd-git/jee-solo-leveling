# JEE Solo Leveling System

A gamified study tracker for JEE prep — leaderboard, XP, ranks, and AI-verified proof-of-work.

## Stack
- **Frontend:** Next.js (React)
- **Backend/DB/Auth:** Supabase
- **AI Verification:** Claude API (vision)
- **Hosting:** Vercel
